# Auditorías de accesibilidad

![Auditorías de accesibilidad en el panel de resultados de comprobaciones](./assets/accessibility/hero.png){align="center"}

La auditoría **Accesibilidad** en Comprobación preliminar evalúa su página con respecto a las Directrices de accesibilidad del contenido web (WCAG) para garantizar que todos, incluidas las personas con discapacidades, puedan usar la página. Al ejecutar una auditoría de comprobaciones, se evalúa la página en relación con estos estándares de accesibilidad y se agrupan los problemas que se encuentran en oportunidades que se pueden revisar y resolver antes de la publicación. Para obtener más información acerca de las comprobaciones de accesibilidad y las directrices que cubren, consulte [Problemas de accesibilidad](/help/documentation/opportunities/accessibility-issues.md).

En el panel de resultados, expanda la categoría **Accesibilidad** para ver si la auditoría se realizó correctamente y la cantidad de oportunidades que encontró. Seleccione la auditoría para abrir su página de detalles y pasar por las oportunidades. Cada oportunidad describe el problema de accesibilidad, la regla WCAG y el nivel de conformidad relacionados, junto con el elemento afectado en la página. Cuando el elemento tiene texto legible, la comprobación preliminar muestra ese texto para que pueda reconocer el elemento con mayor facilidad; de lo contrario, muestra el selector CSS del elemento. Para aprender a interpretar los resultados y resolver las oportunidades, vea [Resultados de auditoría en comprobaciones](../audit-results.md).
